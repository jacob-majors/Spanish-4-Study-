# SA Spanish 4 — Study Tool

A study app that does what Quizlet does for vocabulary and what Conjuguemos does
for verbs — in one place, built from the actual class packets.

## How content gets in

You do not add sets in the browser. Hand Claude a review packet, study guide or
Quizlet export (in chat, or dropped in `packets/`), and Claude writes it into
`data/curriculum.ts` — the vocabulary into `CURRICULUM_SETS`, the test into
`EXAMS`. Push, Vercel redeploys, and it shows up under **Tests** with a
countdown, a topic checklist, a conjugation drill preset and a mock exam built
to match the real format. See [packets/README.md](packets/README.md).

Progress is keyed to the Spanish term, so regenerating a set never resets what
you have already learned.

## What it does

**Vocabulary**
- Sets come from the class packets, cleaned up on the way in (Quizlet PDF exports
  drop the `fi` ligature, so `fght` becomes `fight` and `febre` becomes `fiebre`).
- Five study modes: Flashcards, Learn, Write, Match, and a graded Practice test.

**Better than a plain flashcard app**
- **Spaced repetition.** Every term tracks its own Leitner box per direction
  (es→en and en→es are learned separately). Missed terms come back fast, mastered
  terms get parked for weeks.
- **Forgiving grading.** Typos within one or two characters still count, `to run`
  matches `run`, and `hablar / to speak, to talk` accepts either meaning. Accents can
  be required or forgiven per mode.
- **Accent keys.** A click-to-insert row for á é í ó ú ñ ü ¿ ¡ so a US keyboard is
  not a handicap.
- **Audio** on every term via the browser's speech synthesis, in an Indian
  English voice (Rishi, `en-IN`). The colophon at the foot of every page names
  the voice actually in use. Note that an English voice reads Spanish spelling
  with English phonetics, so it is not a pronunciation model.
- **Practice tests** you configure: how many questions, which types (fill-in-the-blank,
  multiple choice, written, true/false, matching), which direction, and whether to weight the test
  toward what you keep missing. Graded with a letter grade, a full answer key, and a
  one-click retake of only what you missed.

**Conjugation trainer**
- 236 verbs, drilled across the four tenses the class covers, generated by a rule engine rather than a lookup table:
  present, preterite, imperfect, future, conditional, all four perfect tenses,
  present and imperfect subjunctive (-ra and -se), perfect and pluperfect subjunctive,
  affirmative and negative commands, gerund and past participle.
- Handles boot verbs (e→ie, o→ue, e→i, u→ue), spelling changes (-car, -gar, -zar,
  -ger, -guir, -uir, -eer), irregular yo forms, strong preterites, irregular
  participles, and reflexive pronoun placement including command accents
  (`levántate`, `levantémonos`, `sentaos`).
- Pick verbs by group or hand-pick your own; pick exactly the tenses and subjects
  your test covers. Every miss shows the full paradigm.
- A browsable verb-table reference at `/tables`.

**Progress**
- Day streak, mastery per set, accuracy, test history and drill history.
- Everything is stored in your browser. Export a JSON backup from **My sets** to move
  it to another computer.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Deploying to Vercel

The app is a stock Next.js project with no server state and no environment variables,
so it deploys with zero configuration:

```bash
vercel login
vercel --prod
```

Accept the defaults when prompted — Vercel detects Next.js on its own.

## Tests

The conjugation engine has a test suite of 124 assertions against known-correct forms,
plus a sweep over every verb and tense:

```bash
npm test
```

## Layout

```
app/                  routes (home, exams, sets, study modes, drills, tables, progress)
components/           shared UI, including the test runner
data/curriculum.ts    THE CONTENT FILE — vocabulary sets and exam plans
packets/              drop review packets here for Claude to process
lib/
  conjugation/        the verb engine — engine.ts, verbs.ts, types.ts
  curriculum.ts       syncs data/curriculum.ts into the local store
  mockexam.ts         builds a mock exam matching a test's real format
  grade.ts            answer checking (accents, typos, alternatives)
  srs.ts              Leitner scheduling and study-queue ordering
  testgen.ts          practice-test construction
  storage.ts          localStorage store
tests/                engine test suite
```
